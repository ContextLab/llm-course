Quick Guide

Edit the ELIZA rules JSON to customize behavior. Changes apply to Tab 1 in real-time.

Rule Structure

keyword: Word to trigger this rule

rank: Priority (higher = checked first)

pattern: Match template (use * for wildcards)

responses: Array of possible replies

Wildcards

* - Matches any text

(1), (2), ... - Reference captured groups in responses

Synonyms

@belief - Matches any word in the belief synonym group (believe, think, feel, wish)

@family - Matches family members (mother, father, etc.)

Example Pattern

"* i feel *"

Matches: "I feel sad", "Sometimes I feel happy"

Response: "Why do you feel (2)?"
