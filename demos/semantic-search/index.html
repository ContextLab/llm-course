About Search Methods

Semantic Search

How it works: Converts both query and documents into high-dimensional embedding vectors. Computes cosine similarity to find semantically related content.

Strengths:

  • Finds conceptually similar documents
  • Handles synonyms and paraphrasing
  • Language-aware understanding

Weaknesses:

  • Slower (requires embedding generation)
  • May miss exact keyword matches
  • Computationally expensive

Keyword Search (BM25)

How it works: Uses BM25 (Best Matching 25) algorithm based on term frequency-inverse document frequency (TF-IDF) with saturation.

Strengths:

  • Very fast
  • Excellent for exact matches
  • Well-understood algorithm

Weaknesses:

  • Purely lexical matching
  • Misses semantic relationships
  • Sensitive to exact wording

Hybrid Search

How it works: Combines normalized scores from both semantic and keyword search methods using a weighted average.

Formula:

score = α × semantic_score + (1-α) × keyword_score

Benefits:

  • Best of both approaches
  • Configurable trade-offs
  • Robust to query types
